<body-processor>

Body execution processor

Core v2.2.0

Overview

The is an internal processor used by the framework to execute child processors and collect their results. It provides a standardized way to execute processor body content and return the results as a variable list.

Important Notes

  • Internal Use:: Primarily used by framework, not user configurations
  • Body Execution:: Executes child processors and returns results
  • Variable Scope:: Maintains proper variable scope during execution
  • Result Format:: Returns results as appropriate variable type
