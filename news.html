Session Management API, IDE Redesign, HttpClient 5 Migration

🚀

What's New in v2.2.0

Released October 14, 2025

Core Features

  • Session Management API - UUID-based tracking, lifecycle management
  • Token Tracking - HTTP requests, bytes, CPU time monitoring
  • Enhanced Metrics - Real-time performance data
  • Event System - SessionCreated, Started, Completed events
  • Unified Settings - CLI/GUI share config, modern syntax (Bug #39) NEW
  • LogPlugin - New core plugin for console logging NEW

IDE & Quality

  • IDE Redesign - Apple HIG-inspired per-tab workspaces
  • Real-time Updates - WebSocket-based live streaming
  • HttpClient 5 - Modern HTTP client migration
  • 3,091 Tests - Comprehensive coverage & quality (264 new tests in Oct 2025)
  • Plugin Architecture - 57 plugins: 47 core + 10 extension modules IMPROVED

New Website Launch (October 2025)

Complete redesign with modern UX

Along with v2.2.0, we're launching a completely redesigned website! The new site features:

  • Professional design - Modern, clean interface
  • Complete documentation - 57 plugin pages with examples
  • SEO optimized - Better discoverability
  • Developer guides - Creating plugins, architecture
  • Responsive design - Works on all devices
  • Comprehensive examples - Real-world scenarios

Work in Progress: The scale of changes is significant - we've redesigned and rewritten most of the website. While we've taken great care to ensure quality, some issues may still exist. We're actively working on improvements and welcome your feedback on our bug tracker.
